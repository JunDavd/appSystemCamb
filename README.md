# systemcamb app
## aplicación para la gestión de inventario interno de la empresa systemcamb & computer

la aplicación se esta desarrollando para llevar el control de las ventas, los gastos y el inventario interno de la empresa

la aplicación se esta desarrollando con nextjs. esta aplicación se basa en un video tutorial del canal de YouTube EdRoh.

objetivo: sumergirse directamente en la creación de app complejas, tratando de entender el panorama general de la concepción técnica y conceptual de la aplicación para familiarizarse con estos procesos y a partir de estos comenzar a construir desde los conceptos que no se comprenden.
